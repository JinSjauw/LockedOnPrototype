# Locked On
Dit was een prototype voor een game waar ik graag een mix van realtime + strategie ervaring wilde ontwikkelen.

## Technologieën
- C#
- Unity
- HLSL
- Git

## Features
- Speelbaar level
- Point-cloud effect met shaders voor VFX + Compute shader voor het processen van positionering/point selection.
- Terrain scanner VFX via een shader
- Sonar/radar VFX via een shader
- Procedural animation voor quad leg mechtank.
- Simpele enemy AI
